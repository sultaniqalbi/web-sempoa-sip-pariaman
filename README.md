## 📖 Tentang

**Sempoa SIP TC Pariaman** adalah platform digital untuk manajemen lembaga kursus sempoa yang mengintegrasikan sistem pembelajaran, administrasi, dan monitoring dalam satu aplikasi web terpadu.

Sistem ini dikembangkan khusus untuk **Sempoa SIP Training Center Pariaman** guna mendukung transformasi digital dalam pengelolaan lembaga kursus sempoa.

## ✨ Fitur Utama

- 📚 **Manajemen Siswa** — Pendaftaran, data profil, dan tracking progress belajar siswa
- 👩‍🏫 **Manajemen Guru** — Pengelolaan data pengajar dan jadwal mengajar
- 📝 **Catatan Pembelajaran** — Pencatatan materi dan evaluasi harian per siswa
- 📊 **Evaluasi & Raport** — Sistem penilaian dan laporan perkembangan siswa
- 📸 **Galeri Kegiatan** — Dokumentasi aktivitas dan kegiatan lembaga
- 🏠 **Multi-Cabang** — Dukungan pengelolaan beberapa lokasi kursus
- 🔔 **Notifikasi Real-time** — Pemberitahuan otomatis untuk guru dan admin
- 📱 **Absensi RFID** — Sistem absensi otomatis menggunakan kartu RFID
- 💰 **Manajemen Keuangan** — Pencatatan pembayaran SPP dan administrasi
- 🌐 **Progressive Web App** — Bisa diakses seperti aplikasi native di HP

## 📱 Absensi RFID

Sistem ini dilengkapi perangkat keras **absensi berbasis RFID** yang terintegrasi langsung dengan platform web. Guru dan siswa cukup menempelkan kartu untuk mencatat kehadiran secara otomatis.

## 🔒 Keamanan

- Autentikasi berbasis token dengan mekanisme revokasi
- Enkripsi password menggunakan standar industri
- Database terisolasi dan tidak terekspos ke publik
- Validasi dan sanitasi input di semua endpoint
- Proteksi terhadap serangan umum (injection, XSS, CSRF)
- Pembatasan upload file berdasarkan tipe dan ukuran

## 🚀 Deployment

Aplikasi di-deploy menggunakan containerisasi untuk kemudahan dan konsistensi. Panduan deployment tersedia secara internal.
